### 使用方法
1. :rocket: :rocket: :rocket: 先下载数据集[数据集](https://drive.google.com/drive/folders/1VIkBFx5Po0KPIFBYOL_appLVie5wgdyi),解压并且存放到./resource/dataset文件夹下面。
2. :sparkles: :sparkles: :sparkles: 其次window用户运行对应的Makefile.ps1文件，linux用户使用make文件先执行(win : ./Makefile.ps1 init linux : make init) ，其次运行(win ./Makefile.ps1 runDataset linux : make runData)最后运行(win : ./Makefile.ps1 showData, linux : make showData)
3. :tada: :tada: :tada:如果失败，请手动安装 :pushpin: [python](https://www.python.org/downloads/),:pushpin: [uv](https://uv.doczh.com/getting-started/installation/)并且执行:uv init , uv venv ,uv sync来同步环境。
